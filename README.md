# Sto_XAJ_WaveML
**Stochastic state-augmented Xin'anjiang modeling coupled with wavelet-based machine learning for rainfall-runoff simulation**
## Overview

Accurately simulating rainfall-runoff processes remains challenging because hydrological systems exhibit inherent stochasticity associated with uncertainty in internal hydrological states. Conventional deterministic hydrological models cannot explicitly represent this uncertainty.

This repository presents a stochastic state-augmented Xin'anjiang (Sto-XAJ) modeling framework coupled with wavelet-based machine learning for improved runoff simulation across diverse hydroclimatic conditions.

Lévy stable noise is independently introduced into the state update equations of multiple hydrological state variables. Through systematic comparison, the most effective perturbation node is identified. Ensemble discharge trajectories generated by the optimal Sto-XAJ model are then decomposed using wavelet transform and integrated with machine learning models under two input schemes.

The framework is evaluated using **182 selected basins from the 671-basin US CAMELS dataset** with contrasting hydroclimatic characteristics.

## Data

The experiments use 182 selected basins from the 671-basin US CAMELS dataset.

Official dataset page:

https://ral.ucar.edu/solutions/products/camels

The basin-level data used by this project are organized into precipitation, potential evapotranspiration, and observed discharge time series. Potential evapotranspiration (PET) is calculated using the FAO Penman equation.

The example basin file illustrates the required time-series format:

| Column | Description |
|---|---|
| `date` | Observation date |
| `plui` | Precipitation |
| `etp` | Potential evapotranspiration calculated using the FAO Penman equation |
| `discharge` | Observed streamflow |

See [`data/README.md`](data/README.md) and [`data/basins/README.md`](data/basins/README.md) for further details.


## Installation
**Environment Requirements**

The project was developed and tested using the following software environment:

Python: 3.10.8

Keras: 3.11.1

TensorFlow: 2.19.0

Install the Python packages required by the scripts in `src/`.

```bash
pip install numpy pandas scipy matplotlib numba joblib scikit-learn PyWavelets
```

Additional packages may be required by individual scripts, including the GRU and XGBoost implementations. Please check the imports in each script and install the corresponding packages before execution.


## Usage

A typical workflow consists of the following steps:

1. Obtain the required CAMELS data and identify the 182 selected basins.
2. Prepare the static basin attribute table and basin-level time series.
3. Place the prepared files in the expected local data directories.
4. Configure the input and output paths in the relevant Python scripts.
5. Run the deterministic XAJ model as a baseline.
6. Run the stochastic XAJ configurations to compare perturbation nodes.
7. Generate ensemble discharge trajectories using the selected Sto-XAJ configuration.
8. Apply wavelet decomposition and train the machine learning models under Scheme 1 and Scheme 2.


## Data Availability

The complete basin-level time series for all 182 selected basins are not included in this repository because of storage limitations. One example basin file is provided to illustrate the required data format.

Users should obtain the original CAMELS data from the official provider, follow the applicable terms of use, and prepare the selected basin data according to the documentation in the `data/` directory.
